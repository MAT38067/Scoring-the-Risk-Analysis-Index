# Scoring-the-Risk-Analysis-Index
To score a single patient for clinical purposes (RAI-C), we recommend the following link:  https://efrailty.hsl.harvard.edu/ToolRiskAnalysisIndex.html.   

To score a dataset of patients (using the RAI-A, RAI-C, or RAI-ICD), please see the “Scoring the Risk Analysis Index” folder.
